## Objetivo

Realizar las actividades del docente para encontrar soluciones para la propuesta del proyecto, a partir de analisis de ideas actuales que pueden ser incluidas en el proyecto. Tambien realizar un bosquejo visual del prototipo a partir de las ideas seleccionadas del analisis.

## Actividades realizadas

1. Analisis de estado del arte
2. Matriz de atributos
3. Bosquejo del proyecto

## Resultados

Se realizo un bosquejo visual del prototipo que incluye distintas secciones de este, como el interfaz de usuario, formulario de reservas, formulario de cancelacion de reservas y el interfaz de administrador. Cada una de las secciones incluye subsecciones para gestionar lo que se dedcida hacer en cada seccion.

## Aprendizajes

Debido a los puntos de mejora que remarco el docente, creemos que antes de pensar que tenemos una presentacion o parte del proyecto hecho, deberiamos pedir feedback al docente respecto a estos temas para tener todo claro y correcto.
